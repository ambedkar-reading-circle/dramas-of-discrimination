## Question

What is the **Local-mode facilitation flow** — the default posture of the product (README: "nothing is stored server-side by default")?

Settled already by [D1](D1-how-live.md): one concurrent editor, sequential pass-the-keyboard; no realtime layer; Yjs doc persisted to browser storage with **continuous autosave**. Still open here:

- **Projector-first layout** — does the single-device UI target a shared screen readable from across a room?
- **No-account session resume** — how does a community find its Rehearsal again from the same device/browser (device-local Rehearsal list? resume URL?)?
- **Facilitation pacing** — how the recorded step-by-step guidance paces a self-led room with one typist.

### Context
